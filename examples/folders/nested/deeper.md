# One level deeper

You reached this page by stepping into `folders/`, then into `nested/` — which
has no folders of its own, so `Enter` on it went straight to its files.

`Backspace` in the viewer goes back where you came from. In the file list,
`Backspace` is the same idea one directory at a time.

See [folder browsing](../index.md) for what the rest of the keys do.
